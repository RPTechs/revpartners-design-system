# Example deliverables

These are **finished** client HTML docs. Copy the closest one. Do not invent a new chrome recipe.

`docs/01-branded.html` and `docs/02-working.html` are letterhead shells. These files are the real thing.

Pick a genre, duplicate the file, swap the copy. Keep the type scale, padding, 8px boxes, 2px borders, and button pad (`15px 40px`, Inter 700, 16px).

| Genre | File | Use when |
|---|---|---|
| Feasibility / scoping | `feasibility-jesus-image-stripe-checkout.html` | Short “can we do this?” — BLUF, one flow, estimate table |
| Process / decision tree | `process-channel-engine-dedupe.html` | Workflows, forks, merge/stop. Stems that touch cards |
| Technical spec | `spec-mentavi-journey-event.html` | Long spec: TOC, nested ask/stop/info, 3-step lists that stop at orange |
| Implementation one-pager | `one-pager-forecast-purchase-orders.html` | How a HubSpot build works, compact |
| Implementation guide | `guide-chat-visitor-identification.html` | Step-by-step with code samples |
| Operating guide | `guide-tech-scorecard-epic-metrics.html` | Scorecard / RACI / how-we-run-this |

Shared files live in `assets/` (favicon, prism, spec figures). Keep that relative path.

Not in this folder on purpose: marketing landings (RPM-style dark hero), portal indexes, and anything with an orbit diagram pretending to be a brief.
