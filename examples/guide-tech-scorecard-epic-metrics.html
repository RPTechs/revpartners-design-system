Tech Scorecard & Epic Metrics

How we measure delivery — weekly task hygiene for technologists, and project-level epic health for closed work.

BLUF

Two score systems, one bonus. Tech Scorecard = your weekly ClickUp habits (weighted %). Tech Epic Score = closed HubSpot projects (100 pts). Epic performance can add a 0–5% bonus on top of the scorecard.

help FAQ

The questions people actually ask.

compare_arrows Scorecard vs Epic Score — what’s the difference?

Scorecard = micro weekly task hygiene in ClickUp/Databox.
Epic Score = macro project health on closed HubSpot epics (gates, timing, strategist satisfaction).

hourglass_empty Why is Epic Score / Bonus blank or 0%?

Epic scores land on Closeout survey submission. No closed epics in the date range → blank / 0% by design.

timer Tasks with no time estimate?

Default to a 3-hour baseline weight so they still count.

star No Quality / Communication rating — am I penalized?

No. Only tasks with an explicit rating count toward those two scores.

front_hand Partner blockers delayed me?

Flag early in standups. Use pushed-back process. Get manager to set Review status before scores freeze Monday.

key Comment keywords for automated checks?

Acceptance: “Accepted”, “Task Confirmed”, or the acceptance template.
Sprint Review: “Task Complete”, “What we did”, “Closing Out”, or the sprint review template.

edit_calendar Update estimates / start dates after submission?

Only when scope or schedule genuinely shifts. Keep capacity forecasting honest.

build Troubleshooting

Find the layer first. Fixing the wrong layer is how weekends die.

cable Databox connector

Looks like

Empty columns in the report; error indicator in Databox corner.

Identify

Treated Data sheet still looks fine with scores — connector is the culprit.

Fix

Update the metric connector.

code Script / raw data

Looks like

Databox zeros; Task Raw Data empty or weird after a given week.

Identify

Weird values in a filled column → updateSheetTaskRawData (column order drift).
Empty column → fetchTask (custom field rename / not found).

Fix

Have a technologist check the script.

functions Formulas

Looks like

Raw Data has rows, but Treated Data missing scores for a range / whole column.

Identify

Confirm Raw Data is healthy first. Then hunt Treated Data for known-good weeks.

Fix

Check header row (row 2): header name + raw values × task weight.
